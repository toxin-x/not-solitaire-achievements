# Emoji images

Twemoji SVG graphics, self-hosted so the page does not depend on a third-party CDN.

- Source: `@twemoji/svg` 15.0.0 (https://www.npmjs.com/package/@twemoji/svg), plus `1faef.svg` and
  `1f426-200d-1f525.svg`, which are newer than that release and were taken from Puzzmo's twemoji assets.
- Twemoji graphics are copyright Twitter, Inc. and other contributors, licensed under
  CC-BY 4.0: https://creativecommons.org/licenses/by/4.0/
- File names are the emoji's code points joined by `-` (see `emojiUrls` in `../index.js`).
- Not available (the page falls back to the emoji character): `265b` (Grandmaster), `1f0a0` (placeholder `x1`).
