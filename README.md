# Not Solitaire Achievements

A list of every achievement in [(not) solitaire](https://notsolitaire.com), with its emoji, rarity and how to unlock it.

**Site:** https://toxin-x.github.io/not-solitaire-achievements/

Upload your achievements dump from [notsolitaire.com/api/achievements](https://notsolitaire.com/api/achievements) to see which ones you've unlocked and which you're still missing. The file is read in your browser and never uploaded.
